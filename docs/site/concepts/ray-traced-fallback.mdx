When the [screen-space tracer](/concepts/screen-space-reflections) misses, there is a list of pixels whose ray found
nothing on screen. The ray-traced fallback takes that list and traces the rays through the whole scene, using a
bounding volume hierarchy (BVH). A hit gets shaded at the hit point, and the result goes into the same signal as the
screen-space hits, so everything after it (the resolve, the denoiser) sees one input.

Only the misses are traced. That keeps it affordable: the cost scales with how many rays screen space could not finish.

## Providers

The tracer asks a *trace provider* for the first hit along a ray. Two exist:

| Provider | What it is |
| --- | --- |
| `MeshBVHTraceProvider` | Built on [three-mesh-bvh](https://github.com/gkjohnson/three-mesh-bvh). The one that works on a stock install today. |
| `createPmndrsBvhTraceProviderFromObjects` | Built on `@pmndrs/bvh`, the group's engine-free BVH (builders on the CPU and GPU, a WGSL ray walk). Not on npm yet. |

Both give the same hits on the test scenes. They sit behind a small interface (a WGSL snippet plus a bind group), so
another BVH can plug in.

## Using it

{/* snippet: ray-traced */}
```ts
const provider = await MeshBVHTraceProvider.fromObjects(getDevice(renderer), meshes);
const ssr = new ScreenSpaceReflectionsPass(renderer, { trace: { provider } });
```

The ray-traced pass is off unless you pass `trace`. It lights hits with the scene's environment (or the probes), and
with the scene's directional lights, shadowed by one ray each. Pass `trace.settings` to tune the ray budget, length,
origin offset, and whether on-screen hits are reused instead of re-traced.

## Things to know

- **Cost.** It is the most expensive source. `maxTracedRaysPerFrame` and `maxRaysPerTile` cap it, and
  `missRoughnessThreshold` limits it to glossy misses.
- **Static BVH.** The BVH is built from the meshes you give it. Build it again when the scene's geometry changes.
- **Hit materials.** Hits are shaded from a per-triangle material table (colour, roughness, metalness), not from your
  full material graph. Colours match three's on-screen look closely for standard materials.
- **Bindings.** The pass adds its own storage buffers and textures to the provider's. If the total passes the
  device's limit, the build fails with what to change. See [Troubleshooting](/guides/troubleshooting).
