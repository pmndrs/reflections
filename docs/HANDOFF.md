# Handoff board

The working state of the project: who is on what, which interfaces the workstreams agreed on, and where each one stopped. `docs/SPEC.md` is the plan; this is the log of executing it. Update your row when you stop, even mid-task.

## How we work (agents read this first)

- **Build features first.** Get a pass working end to end on a real GPU (`pnpm check`), commit, move on. Don't sink time into squeezing milliseconds or making a test match an expectation. If a number is off, write it down (row below, or `DIVERGES.md` if it's a divergence) and keep going. Measurement is for the **gates** in SPEC's roadmap and for big decisions, not for every step.
- **Time-box.** If something fights you for more than ~30 minutes of attempts, record what you tried in your row's "stuck on" and move to the next part of your scope.
- **Diverging from a source is fine. Hiding it isn't.** Every knowing difference from FFX, idTech, three, Lagarde, etc. goes in `docs/DIVERGES.md`.
- **Commit after every run** (CLAUDE.md rule 4): what was tried, numbers, verdict, failures included. Explicit paths, never `git add -A`.
- **Stay in your lane.** Each stream owns the paths in its row. Touching a shared file (`packages/*/src/index.ts`, `src/*.ts`, `package.json`, `scripts/run-headless.mjs`) is allowed but keep the edit to adding your exports or your check, so merges stay trivial.
- **Stopping a server:** kill by port (`lsof -ti tcp:<your port> | xargs kill`), never `pkill -f vite`. A pattern kill takes down every other worktree's server too.
- **Ports.** Each worktree runs its examples server on its own port: `REFLECTIONS_PORT=<port> pnpm examples` / `REFLECTIONS_PORT=<port> pnpm check`. 5370 is the maintainer's own server: agents and the lead never use it (the lead runs main-checkout checks on 5389). `pnpm check` reuses any server already on its port, so a wrong port means testing someone else's build. 5310 belongs to another project.

### Radiance fallback (SSSR miss → probes/env), used by W3 now, filled by phase 2

A WGSL snippet plus a bind group, like the trace seam:

```wgsl
fn sampleRadianceFallback(P: vec3f, dir: vec3f, roughness: f32) -> vec3f
```

W3 ships a default implementation (a single `texture_cube<f32>` environment, or a constant colour) and takes any other snippet + bind group layout at pipeline creation. As built (W3): `P` and `dir` are world space; `roughness` is **perceptual**: `sqrt(alpha)` along the mirror direction for reflective pixels above the roughness threshold and, by default, for screen-space misses too (each pixel its own lookup, lerped by hit confidence; W30, D3100); with `settings.fallbackRoughness: 'mirror'`, misses take FFX's roughness 0 along the sampled direction. Traced misses (`core/src/trace/`) still use roughness 0 (D900). The snippet's bindings live in `@group(1)`; pass its layout as `radianceFallback.layout` and the bind group as `inputs.fallbackBindGroup`. It may read the tracer's uniform block `P` (`P.iblFactor`, `P.fallbackColor`).

Filled by W7 (phase 2): `probeRadianceFallback(set: ProbeSet)` returns `{ wgsl, layout, bindGroup }`. Its `sampleRadianceFallback` is `probeRadianceWithEnvironment(P, dir, roughness) * P.iblFactor` over the set's lookup module at `@group(1)` (atlas, sampler, table: 1 storage buffer). The same object plugs into `createScreenSpaceReflections({ radianceFallback })` + `inputs.fallbackBindGroup` and `createTracedReflections({ radianceFallback })` + `fallbackBindGroup` (traced misses, and `fallbackHitShading`'s probes at the hit along N at roughness 1). The same set can also be the pass's hit shading (`hitSpecularShading` / `hitShading: probeHitShading(device, set)`, group 3): that copy's names carry `_g3`, and the passes keep the lookup's shared includes once (`dedupeWgslChunks` over `markedChunkWgsl` chunks; W64, D4901). A seam that concatenates the lookup's WGSL into a module built elsewhere should run the module through `dedupeWgslChunks` too.

### Frame contract inputs (W4 → W3's three adapter, later)

W3 develops on synthetic, analytic inputs written by compute (exact depth/normal for a plane and boxes), so it never waits on W4. W4 produces the same textures from a three scene, matching SPEC's frame-contract table. The three SSSR node joins the two after both merge.

W4's side, as landed:

```ts
// packages/core/src/frame/contract.ts (exported from @pmndrs/reflections/core)
interface FrameInputs { width; height; textures: FrameTextures; conventions: FrameConventions; camera: FrameCamera; frameIndex }
interface FrameTextures { depth; normal; roughness: { texture, channel }; metalness: { texture, channel }; albedo; motion; sceneColor; lit? } // GPUTexture handles
interface FrameConventions { depthInverted; depthLinear; normalUnpackMul; normalUnpackAdd; roughnessIsPerceptual; roughnessUnpack?: { mul, add } /* W34, default identity */; motionVectorScale: [x, y]; sceneColorSpecular: 'none' | 'direct' }
// FrameCamera: denoiser-core's FrameCamera fields (view, projection, prevView, prevProjection, jitter, near, far, position, reversedDepth) + prevViewProjection
//   + projectionJittered? (F1: `projection` is unjittered when the adapter is given it, D405)

// packages/three/src/frame/FrameGBuffer.ts (exported from @pmndrs/reflections/three)
const gbuffer = new FrameGBuffer(renderer, { lit?: boolean | 'auto', motion?: 'uv' | 'ndc', width?, height? });
const frame: FrameInputs = gbuffer.render(scene, camera, { jitter?, projection? /* unjittered */ }); // each call = one frame of history
gbuffer.resetHistory(); // next render: prev = current, motion 0
gbuffer.textures.normalRoughness; // the three textures, for TSL sampling
```

Layout from three: depth32float; normal = rgba16float world normal (mul 1, add 0) with perceptual roughness in .a; albedo = rgba8unorm base colour with metalness in .a; motion = rg16float uv-space, current − previous, `motionVectorScale` [1, 1] (MRT slot and texture named `velocity`, which three needs for instanced/skinned/batched history, D700); sceneColor = rgba16float emissive + direct + indirect diffuse (no specular). Three-only, with `lit` when the device allows 46 B/sample (W27, `specular: 'auto'`): `textures.specular` rgba16float (rgb = three's env-specular single scattering, a = its specular occlusion x env intensity) and `textures.shadingRoughness` r16float (three's geometry-adjusted roughness); not in `FrameTextures`, read by the three composite only.

### Trace seam (W8 → @pmndrs/bvh, W7)

```ts
// packages/core/src/trace/provider.ts (exported from @pmndrs/reflections/core)
interface BindingSlot { group: number; firstBinding: number }          // = ddgi's BindingSlot
interface TraceProvider {
  name: string;
  code(slot: BindingSlot): string;   // bindings at slot, in `entries` order; defines traceFirstHit (+ traceHitMaterial if capabilities.hitMaterial)
  entries: readonly ModuleBindingEntry[]; resources(): readonly GPUBindingResource[]; version: number; storageBufferCount: number;
  capabilities: { hitNormal: boolean; hitMaterial: boolean; anyHit?: boolean; shadingNormal?: boolean };  // anyHit: W25, shadingNormal: W28
  layoutVersion?: number;            // @pmndrs/bvh: GPU_LAYOUT_VERSION, checked by the provider at start-up
}
```

```wgsl
// declared by the pass (HIT_WGSL) before the provider's code
struct Hit { t: f32 /* < 0: miss */, triangle: u32, barycentrics: vec2f /* weights of corners 1, 2 */, material: u32, instance: u32, normal: vec3f /* world, 0 if !hitNormal */, frontFace: bool }
struct HitMaterial { albedo: vec3f, emissive: vec3f }
fn traceFirstHit(origin: vec3f, dir: vec3f, tMax: f32) -> Hit                 // provider
fn traceHitMaterial(hit: Hit) -> HitMaterial                                  // provider, or the pass's grey default
fn traceAny(origin: vec3f, dir: vec3f, tMax: f32) -> bool                     // provider if capabilities.anyHit, else the pass's (traceFirstHit) (W25)
fn traceHitShadingNormal(hit: Hit) -> vec3f                                   // provider if capabilities.shadingNormal (vertex normals at hit.triangle x barycentrics, world, any length/side; 0 = none), else 0 (W28, D1700)
fn traceLightVisible(P: vec3f, N: vec3f, L: vec3f, tMax: f32) -> bool         // pass: shadow ray, origin offset as D8; true with hitShadows off (W25)
fn shadeTracedHit(hit: Hit, P: vec3f, N: vec3f, dir: vec3f) -> vec3f          // HitShading (pass option); may call sampleRadianceFallback. N: the shading normal if any, on the ray's side
```

The traced pass binds group 0 (itself: 3 storage buffers, 4 storage textures), 1 (radiance fallback, same snippet as SSSR), 2 (provider), 3 (hit shading: `environmentHitShading`, or W28's `probeHitShading(device, set | lookup options)` = lookup atlas / sampler / table at 0..2 + light uniform at 3 + a multi-size set's atlases 1.. at 4.. (W47, D4702), 1 storage buffer; three picks it when `scene.environmentNode` is `reflectionProbes(probes)`). With 3 storage buffers of its own, a provider may use 5 on a default device, 4 with the probe fallback (its table is one more). F2: `createTracedReflections` counts all four groups (storage buffers and storage textures; `RadianceFallback` / `HitShading` declare theirs with `storageBufferCount` / `storageTextureCount`) against `device.limits` and throws with the limit to raise.

**Plugged in (W14, on bvh `main` since W48):** `PmndrsBvhTraceProvider` in `packages/core/src/trace/pmndrsBvh.ts` is that wrapper; the three items below landed first on bvh's `reflections-integration` branch and are now on its `main` (layout 2: `bvhTraceClosest(BvhRay) -> BvhHit` with `normal` and per-instance `material`, `GPU_LAYOUT_VERSION` 2). What follows is the pre-W14 note, in the branch's `gi*` names.

**For @pmndrs/bvh to plug in:** a ~40-line wrapper whose `code(slot)` is `traceModuleWgsl(slot)` (+ its dependencies) followed by `traceFirstHit` calling `giTraceClosest(GiRay(origin, 0.0, dir, tMax))` and mapping `GiHit` (t, triangle, barycentrics, frontFace map one to one). What it lacks today: (1) a hit normal (GiHit has none; the walk has the triangle's corners and the instance transform, so a `giHitNormal(hit)` helper or a `normal` field would do; without it `hitNormal: false` and the pass shades with -dir); (2) an instance → material table (an extra binding, or a user word in the instance record); (3) the exported `GPU_LAYOUT_VERSION` constant (the split doc plans it; not in the source yet). Its 3 storage buffers fit (6 of 8 with the pass).
