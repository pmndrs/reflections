| D5061 | RT / bilateral fill of untraced misses (W74, X4; reused by X5) | Kopf et al. 2007 (JBU): spatial Gaussian over low-res taps x a range Gaussian on a full-res colour guide, ~5x5. Game variants: geometric range weights over a bilateral 2x2 with a nearest-depth fallback. | Core `bilateralFill` (`packages/core/src/bilateral/fill.ts`): an includer-defined tap grid (X4: 2x2 quads; X5: half-res texels), footprint 2 / 3 / 4 cells, weight = spatial (includer's; X4 flat 1) x saturate(1 - plane distance / (0.01 x view distance)) x pow(dot(n_p, n_q), 16) x saturate(1 - \|dr\| / 0.1) (perceptual) x source mask (X4 default: RT_SOURCE traced hit, traced miss, on-screen traced hit; not screen-space hits, not capped). Normalised: rgb and confidence by weight, ray length and hit distance by weight x confidence (hits only). X4 uses `bilateralFillMajority` (review fix 1): the coverage class (hits, confidence >= 0.5, or misses) with the larger weight wins and the result is that class alone, with its dominant source, so mixed coverage never reaches the composite's D2400 blend as a partial confidence. Weight sum < 0.01: the pixel keeps intersect's probe fallback and source 'capped' (as an entry past the ray budget).
