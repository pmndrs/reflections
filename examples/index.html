Demos

  • showcase — start here: the whole pipeline on real assets (car concept, toy car, chess set on a mirror floor; Sponza with a polished floor). Probes, SSR, ray-traced fallback and denoising as toggles, an off baseline, debug views, GPU ms. Needs pnpm assets. ?scene=carConcept|toyCar|chess|sponza, ?rt=1, ?denoise=0, ?off.
  • ssr — screen-space reflections in three on the scene kit. ?scene=mirrorWall|offscreen|contact|roughnessRamp|boxRoom|moving|explainer|rooms|facingMirrors, ?rt=1 ray-traced misses, ?hit=final mirrors-in-mirrors, ?probes=0.
  • probes — live reflection probes: a spinning torus and a colour-cycling light, re-captured every frame. Same API as three.js #35046 (built alongside Ben Houston). ?static to freeze. ?grid for the test grid, ?refit for LightProbeGrid re-fit.
  • scenes — the scene kit and every G-buffer target (depth, normal, roughness, motion, scene colour without specular). ?scene=…

Core (raw WebGPU, no three)

  • sssr-core — the screen-space tracer on exact analytic inputs, with debug views and variant parity.
  • probe-core — the core probe set and its radiance fallback.
  • bc6h — the BC6H GPU encoder against the hardware decoder.

Benches and tests

  • probe-bench — probe layout × format bench (cube array, 2D array, octahedral; rgba16f, rgb9e5, rg11b10, BC6H).
  • ssr-bench — ours vs three r187's SSRNode (± its denoiser): error, flicker, GPU ms.
  • regressions — GPU repros of review bugs, each failing before its fix.
