@pmndrs/reflections examples

Each page also accepts ?manual (render loop stopped). See docs/HANDOFF.md for status.

Start here

  • quickstart — the smallest complete page: a three.js scene (glossy floor, PBR objects, room environment) with reflections from one Reflections.create(); screen space, a baked probe, the denoiser. ?rt=1 ray-traced fallback, ?preset=performance, ?denoise=0. Probes only (the cheapest path): quickstart/probes.html.
  • r3f — the same scene in React Three Fiber v10 (WebGPURenderer): a useReflections() hook over Reflections. Same query keys.

Demos

  • showcase — start here: the whole pipeline on real assets (car concept, toy car, chess set on a mirror floor; Sponza with a polished floor). Probes, SSR, ray-traced fallback and denoising as toggles, an off baseline, debug views, GPU ms. Needs pnpm assets. ?scene=carConcept|toyCar|chess|sponza, ?rt=1, ?denoise=0, ?off.
  • showcase/bench — the tuning bench: every setting (SSR, ray tracing, hybrid, denoiser, probes, AA / upscaler, specAA, scene, three's SSR) on one panel, two methods side by side (ours, three SSR ± its denoisers, path traced, probes only) as a split, side by side or a difference heat map, Measure vs the path tracer per region (drag to add one), copy as code. Every setting with its default, trade-off and GPU cost: docs/SETTINGS.md. Needs pnpm assets (the path tracer and three's FFX need the sibling Denoiser repo). ?scene=carConcept&pose=w50&left=ours-rt&right=pathtraced.
  • ssr — screen-space reflections in three on the scene kit. ?scene=mirrorWall|offscreen|contact|roughnessRamp|boxRoom|moving|explainer|rooms|facingMirrors, ?rt=1 ray-traced misses, ?hit=final mirrors-in-mirrors, ?probes=0.
  • probes — live reflection probes: a spinning torus and a colour-cycling light, re-captured every frame. Same API as three.js #35046 (built alongside Ben Houston). ?static to freeze. ?grid for the test grid, ?refit for LightProbeGrid re-fit.
  • probes — reflection probes (three #35046 API) in Ben's rooms. ?grid for the test grid, ?refit for LightProbeGrid re-fit.
  • babylon — mirrorWall on Babylon.js (WebGPUEngine) through @pmndrs/reflections/babylon: core SSR + probe set on Babylon's device, frame-graph composite. ?ssr=0, ?probes=0, ?view=…, ?variant=workgroup.
  • pixi3d/arcade — a neon arcade built with pixi-3d (@pixi/3d, closed beta) through @pmndrs/reflections/pixi: pixi Text and Graphics as ContainerTextures on 3-D planes, pixi-3d's depth and motion plus one G-buffer pass, core SSR + probes on pixi's device, composited by a pixi Filter. Without the beta in examples/pixi3d/vendor/ it shows the setup notice (README). ?ssr=0, ?probes=0, ?denoise=0, ?view=…, ?variant=workgroup, ?manual.
  • scenes — the scene kit and every G-buffer target (depth, normal, roughness, motion, scene colour without specular). ?scene=…

Core (raw WebGPU, no three)

  • sssr-core — the screen-space tracer on exact analytic inputs, with debug views and variant parity.
  • probe-core — the core probe set and its radiance fallback.
  • bc6h — the BC6H GPU encoder against the hardware decoder.

Benches and tests

  • probe-bench — probe layout × format bench (cube array, 2D array, octahedral; rgba16f, rgb9e5, rg11b10, BC6H).
  • ssr-bench — ours vs three r187's SSRNode (± its denoiser): error, flicker, GPU ms.
  • regressions — GPU repros of review bugs, each failing before its fix.
