Reflections for WebGPU

Reflection probes, screen-space reflections and a ray-traced fallback, composed per pixel and denoised. The core is engine-agnostic; three.js is the main adapter, with Babylon.js and pixi.js beside it. Each example is one page with its source on GitHub and an info panel that says what to look at.

Checking WebGPU…

These pages need a browser with WebGPU (current Chrome or Edge, Safari 26+, Firefox 141+ on Windows). Pages marked streams models load Khronos sample models from a CDN; the first load is a few tens of MB.
