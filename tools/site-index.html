@pmndrs/reflections examples

Reflections for WebGPU: probes, screen-space reflections and a ray-traced fallback, composed per pixel. Docs · GitHub

Showcase Start here. A car concept, a toy car and a chess set on a mirror floor, and Sponza with a polished floor. Switch probes, screen-space reflections, the ray-traced fallback and the denoiser on and off, and look at the debug views. ?scene=carConcept|toyCar|chess|sponza, ?rt=1, ?denoise=0.

These pages need a browser with WebGPU (current Chrome, Edge or Safari Technology Preview). The models (Khronos glTF Sample Assets) load from a CDN and the first load is a few tens of MB.

More demos

  • ssr — screen-space reflections on small test scenes. ?scene=mirrorWall|offscreen|contact|roughnessRamp|boxRoom|moving|explainer|rooms|facingMirrors, ?rt=1 ray-traced misses, ?probes=0.
  • probes — live reflection probes in a room: a spinning torus and a colour-cycling light, captured every frame. ?static, ?grid, ?refit.
  • babylon — the same screen-space reflections on Babylon.js (WebGPUEngine). Experimental.
  • scenes — the test scenes and every G-buffer target (depth, normal, roughness, motion, scene colour).

Developer pages

Checks and benches that the repository runs on a real GPU. They are here to read and poke at, not as demos.

  • sssr-core — the screen-space tracer on exact analytic inputs (raw WebGPU, no three).
  • probe-core — the core probe set and its radiance fallback (raw WebGPU).
  • bc6h — the BC6H GPU encoder against the hardware decoder.
  • probe-bench — probe layout and format bench.
  • ssr-bench — ours against three's SSRNode: error, flicker, GPU ms.
  • regressions — GPU repros of review bugs.

The repository also has a tuning bench and a path-traced comparison page. They need the denoiser's OIDN package and a local checkout, so they are not on this site; see the settings reference.
